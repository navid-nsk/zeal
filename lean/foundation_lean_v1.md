# ZEAL — mathematical spine for Lean formalization, version 1 (extracted from the frozen foundation v7.5; no experimental numbers, no research history, no practical problems, no conjectures)

**Purpose.** The statements below are the formalization targets, in dependency order. Each carries its exact hypotheses as frozen; a formalizer may add hypotheses only in `extra_conditions_v1.md` (never here). Attribution tags [B]/[BC]/[O] are kept because the paper needs them; Lean does not settle priority. Module names refer to `lean/zeal/ZEAL/…`. Everything is finite-dimensional and discrete unless stated; the continuous statements are listed last and may be deferred.

## 0. Basic objects (`Basic/`)
- **D0.1 (weighted finite set).** A finite type V with a weight μ : V → ℚ, μ_p > 0, Σ_p μ_p = 1. Cell = non-empty finite subset a ⊆ V; μ(a) = Σ_{p∈a} μ_p > 0; cell mean of v : V → ℚ (or ℝ): ⟨v⟩_a = Σ_{p∈a} μ_p v_p / μ(a). A zoning Z is a partition of V into cells; the projection P_Z v = Σ_a ⟨v⟩_a 1_a; Z′ ≼ Z (Z′ coarsens Z) iff every cell of Z′ is a union of cells of Z. (`WeightedFiniteSet.lean`)
- **D0.2 (directed graph with arc costs).** Finite vertex set V, arcs E ⊆ V × V with cost c : E → ℝ; a walk, its cost, directed cycles; "no negative directed cycle". Extended shortest-path distance D(i,j) ∈ ℝ ∪ {+∞}: D(i,i) = 0, D(i,j) = inf over walks (−∞ excluded by the no-negative-cycle hypothesis; +∞ if no walk). Triangle inequality D(i,k) ≤ D(i,j) + D(j,k) (with +∞ conventions); D(i,j) + D(j,i) ≥ 0 when both finite. (`DirectedGraph.lean`)
- **D0.3 (difference-constraint system).** Variables φ : V → ℝ; bounds l ≤ φ ≤ u (l_p ≤ u_p real; infinite bounds allowed as options); arc constraints φ_q − φ_p ≤ c_pq for (p,q) ∈ E. Feasible set Φ. Augmented graph: V ∪ {0} with arcs p→q (c_pq), 0→p (u_p), p→0 (−l_p). (`DifferenceConstraints.lean`)

## 1. Transport (`Transport/`)
- **T1.1 (projection identities) [B].** For v, w : V → ℝ and a zoning Z: P_Z is linear, idempotent, self-adjoint in ⟨·,·⟩_μ, fixes constants; P_{Z′} P_Z = P_{Z′} for Z′ ≼ Z; Var_μ(v) = Var_μ(P_Z v) + ‖(I − P_Z) v‖²_μ; cov_μ(P_Z v, P_Z w) = ⟨P_Z v, w − w̄⟩_μ. (`FeasibleSet.lean` or a `Zoning/Projection.lean`)
- **T1.2 (lattice structure of Φ) [B].** Φ (D0.3) is closed under coordinatewise min and max; if the augmented graph has no negative directed cycle, Φ ≠ ∅ and u*_j := min_i (u_i + D(i,j)) (over i with finite D), l*_i := max_j (l_j − D(i,j)) are the top and bottom of Φ: u*, l* ∈ Φ and l* ≤ φ ≤ u* for all φ ∈ Φ. Conversely Φ ≠ ∅ implies no negative augmented cycle. (`ShortestPathClosure.lean`)
- **T1.3 (support function; weak duality) [B].** For d : V → ℝ with Σ d = 0, h_Φ(d) := sup_{φ∈Φ} dᵀφ. For every y ≥ 0 on the arc constraints and every split of r = d − Aᵀy into r⁺ − r⁻ (r^± ≥ 0): h_Φ(d) ≤ Σ_e y_e c_e + Σ_p (r⁺_p u_p − r⁻_p l_p) whenever the right side is finite. (`SupportFunction.lean`) — this is the inequality the certificate checker uses.
- **T1.4 (Theorem A — grounded-flow representation) [B/BC].** Under "no negative augmented cycle" and Σ d = 0, with d⁺ = max(d,0), d⁻ = max(−d,0), D̄(q,p) := min{D(q,p), u*_p − l*_q}: h_Φ(d) = min over couplings π ∈ Π(d⁻, d⁺) of Σ_{q,p} π_qp D̄(q,p). (`GroundedFlowDual.lean`; proof: LP duality of the min-cost flow with a ground node + path decomposition; the ≤ direction via the potentials u*, l* and T1.3 suffices for the certificate chain; the = direction is the full theorem.)
- **T1.5 (value-face criterion) [BC/O].** With V*(d) := Σ d⁺_p u*_p − Σ d⁻_q l*_q: h_Φ(d) ≤ V*(d) ≤ Σ d⁺ u − Σ d⁻ l, and h_Φ(d) = V*(d) iff u*_p − l*_q ≤ D(q,p) for all q ∈ supp d⁻, p ∈ supp d⁺. (`SupportFunction.lean`)
- **T1.6 (Wasserstein reduction) [B].** If every arc constraint has the symmetric form |φ_j − φ_i| ≤ L η_ij (L ≥ 0, η > 0 symmetric) and d is balanced on every connected component, then sup{dᵀφ : arc constraints only} = L · W₁(d⁻, d⁺) with the shortest-path metric d_η; if d is not componentwise balanced the supremum is +∞. (`WassersteinReduction.lean`)
- **T1.7 (saving identity) [BC/O].** For ψ ∈ Φ: h_Φ(d) − dᵀψ = min_π Σ π_qp D̄_ψ(q,p) with D̄_ψ(q,p) = D̄(q,p) − (ψ_p − ψ_q) ≥ 0; and with A_p = u*_p − ψ_p, B_q = ψ_q − l*_q, C_qp = A_p + B_q, D_ψ(q,p) = D(q,p) − (ψ_p − ψ_q): V*(d) − h_Φ(d) = max_π Σ π_qp [C_qp − D_ψ(q,p)]₊. (`SavingIdentity.lean`)
- **T1.8 (regime theorem) [O].** With H := V*(d) − dᵀψ > 0 and G := (V* − h_Φ)/H: G = 1 − H⁻¹ min_π Σ π_qp min{C_qp, D_ψ(q,p)} ∈ [0,1]; if a coupling π₀ and ρ ≥ 0 satisfy Σ π₀ D_ψ ≤ ρ H then G ≥ (1−ρ)₊; if D_ψ(q,p) ≥ a C_qp for all source–sink pairs with C_qp > 0 (a ≥ 0) then G ≤ (1−a)₊; exceptional-set version for 0 ≤ a ≤ 1: G ≤ (1−a) + a F_E with F_E = H⁻¹ max_π Σ_{(q,p)∈E} π_qp C_qp. (`RegimeTheorem.lean`)

## 2. Realization (`Realization/`)
- **D2.1 (one-dimensional gradient class).** N intervals of length h; derivative boxes G_i = [g⁻_i, g⁺_i] (finite), w_i = g⁺_i − g⁻_i; the discrete relaxation Φ¹ᴰ_grad = {v : v_{i+1} − v_i ∈ (h/2)(G_i + G_{i+1})}; the function class 𝓕 = {f ∈ W^{1,∞} : f′ ∈ G_i a.e. on interval i} (continuous version, deferred: represent f by its interval means and the integrals of f′). (`OneDimensional.lean`)
- **T2.2 (exact one-dimensional theorem) [BC/O].** For Σ d_i = 0, b_0 = b_N = 0, b_i = −Σ_{j≤i} d_j, s_G(z) = sup_{γ∈G} zγ: U_𝓕(d) = h Σ_i ∫₀¹ s_{G_i}((1−t) b_{i−1} + t b_i) dt and U_Φ(d) = (h/2) Σ_i [s_{G_i}(b_{i−1}) + s_{G_i}(b_i)]; U_Φ − U_𝓕 = (h/2) Σ_{i : b_{i−1} b_i < 0} w_i |b_{i−1} b_i| / (|b_{i−1}| + |b_i|) ≤ (h/8) Σ_i |d_i| w_i. (The formalization may state the discrete identity for U_Φ and the integral formula as a definition of U_𝓕 in terms of piecewise-linear coefficient functions; the inequality chain is then elementary.) (`OneDimensional.lean`)
- **D2.3 (lifted set X^(m); code M = 2m).** Mesh nodes of spacing h/(2m) on the pixels of a finite cell; node value bounds = intersection of the value boxes of the pixels containing the node; segment constraints x_b − x_a ∈ (h/(2m)) · ∩{G_ip : p ⊇ [a,b]} (intersected tangential box on pixel boundaries); two linear maps 𝒞_m (pixel means by averaging the sub-pixel centre nodes) and 𝓑_m (pixel means of the bilinear interpolant). (`LiftedGraph.lean`, `BilinearFields.lean`)
- **T2.4 (lifted outer–inner theorem — discrete core) [O].** U_B^(m)(d) := sup_{X^(m)} dᵀ𝓑_m x ≤ U_X^(m)(d) := sup_{X^(m)} dᵀ𝒞_m x ≤ U_B^(m)(d) + Σ_p |d_p| β_p^(m), with β_p^(m) ≤ (h/8m)(w_1p + w_2p). The inequality U_B ≤ U_X and the gap bound follow from the segment constraints alone (the half-tent identity: centre − bilinear mean ∈ a bounded interval); the continuous inclusions T_m(𝓕_box) ⊆ X^(m) and I_m(X^(m)) ⊆ 𝓕_box are the deferred continuous part. (`OuterInner.lean`)
- **T2.5 (conditioned lifted outer) [O].** For linear averaging rows A (nonnegative, row sums 1): A 𝒞_m T_m f = A𝒫f, hence sup{dᵀ𝒫f : f ∈ 𝓕_box, A𝒫f = y} ≤ sup{dᵀ𝒞_m x : x ∈ X^(m), A𝒞_m x = y} (given the continuous inclusion). Discrete core: for any x-set S and linear A, sup over {x ∈ S : Ax = y} of a linear functional is a support function of a polyhedron. (`OuterInner.lean`)
- **T2.6 (map-level brackets; feasibility-preserving improvement) [B/O].** For weights w_j ≥ 0 and vectors d_j: Σ_j w_j max{h(d_j)², h(−d_j)²} ≥ sup_Φ Σ_j w_j (d_jᵀφ)²; for a convex quadratic Q and polytope P, x⁰ ∈ P, R ⊆ V, P_R(x⁰) = {x ∈ P : x_i = x⁰_i, i ∉ R}: any x ∈ P_R(x⁰) with ∇Q(x⁰)ᵀx ≥ ∇Q(x⁰)ᵀx⁰ satisfies Q(x) ≥ Q(x⁰). (`OuterInner.lean`)

## 3. Zoning statistics (`Zoning/`)
- **D3.1 (complete zonings; classes).** Partitions of V; focal window class and population-fat class at a location (cell ⊆ eligible set E_x, x ∈ cell, μ(cell) ≥ p μ(W_x)); fixed-K balanced contiguous class on a graph. (`Partitions.lean`, `CompleteZonings.lean`)
- **T3.2 (pair differences; rank sets) [B/O].** For named locations with pairwise certified lower bounds ℓ_jk ≤ θ_j − θ_k on a common class: N⁻_j = {k : ℓ_kj > 0}, N⁺_j = {k : ℓ_jk > 0}; the tie-compatible rank interval of j is contained in [1 + |N⁻_j|, |N| − |N⁺_j|]; population version with weights. **Proposition A′:** if Z₀ is a complete zoning and N′ = {j : the Z₀-cell of j satisfies the focal requirement at j}, then Z₀ ∈ C_{N′} (non-empty). **Disjoint-window exactness:** if the eligible sets of x, y are disjoint and the background rule admits singleton completion, inf over the pair class of θ_x − θ_y = inf_{a ∈ 𝒜_x}⟨f⟩_a − sup_{b ∈ 𝒜_y}⟨f⟩_b. (`CompleteZonings.lean`)
- **T3.3 (set-partitioning LP; Theorem B1 charged pricing) [BC/O].** Cells C with contributions n_C, d_C; K-partitions Z with D(Z) = Σ d_C ≥ D_min > 0; slope β(Z) = N(Z)/D(Z). For any (π, θ, b) and any ε with n_C − b d_C − π(C) − θ ≤ ε for every admissible cell: β(Z) ≤ b + max{0, (1ᵀπ + K(θ + ε))/D_min} for every admissible K-partition with D(Z) ≥ D_min; sign-dependent form with D_min ≤ D(Z) ≤ D_max. (`SetPartitioning.lean`, `ChargedPricing.lean`)
- **T3.4 (unit reassignment decomposition) [O].** For zonings Z, Z′ with matched labels, M = {u : c_Z(u) ≠ c_{Z′}(u)}: mov² = Σ_{u∈M} μ_u (m_{c(u)} − m′_{c′(u)})² + Σ_{u∉M} μ_u (m_{c(u)} − m′_{c(u)})² = μ(M) C̄²_M + R_stay with R_stay = Σ_a b_a H_a² / μ(a′)², b_a = μ(a ∩ a′). (`Partitions.lean`)

## 4. Identification (`Identification/`)
- **T4.1 (fibers; nullspace criterion) [B].** A functional T is identified on 𝓕 from A iff T is constant on every fiber {f ∈ 𝓕 : A𝒫f = θ}; for a linear model space and linear T iff T vanishes on ker(A𝒫) ∩ model space. (`Fibers.lean`, `Nullspace.lean`)
- **T4.2 (reconstruction identities) [B].** In a finite-dimensional inner-product space with projection P: for r = (I−P)t, s = (I−P)e, Pe = Pt, r, s ≠ 0, ‖t − t̄‖² > 0: ‖t − e‖² = ‖r‖² + ‖s‖² − 2⟨r,s⟩ and R²(e) = 1 − W(1 + m² − 2ρm) with W = ‖r‖²/‖t − t̄‖², m = ‖s‖/‖r‖, ρ = ⟨r,s⟩/(‖r‖‖s‖); shrinkage: R(κ) − R(κ*) = ‖s‖²(κ − κ*)², κ* = ⟨r,s⟩/‖s‖²; non-worsening ⇔ κ(κ − 2κ*) ≤ 0. (`ConditionedSets.lean` or `Reconstruction.lean`)
- **T4.3 (exact vs approximate conditioning; one-dimensional tent example) [O].** For −1 < c < 1, among 1-Lipschitz f on [0,1] with f(0) = 0, f(1) = c, the maximum mean is attained uniquely by f(x) = min{x, 1 + c − x}; no continuous piecewise-linear function on a mesh omitting (1+c)/2 attains that mean. (Deferred: needs real analysis; optional.)

## 5. Inference (deferred, probabilistic; `Inference/` only if time permits)
- **T5.1 (simultaneous support-function envelope).** Finite query set, compact weight families 𝒲_j, y = θ + ε: L_j(θ) ≥ L_j(y) − sup_{𝒲_j} wᵀε and U_j(θ) ≤ U_j(y) + sup_{𝒲_j}(−wᵀε) (deterministic inequalities — formalizable now); outer-family corollary with 𝒲̂_j ⊇ 𝒲_j and verified data endpoints. The exchangeable-rank calibration guarantee (Pr{M ≤ M_(k)} ≥ k/(B+1)) is a finite exchangeability statement — formalizable with Mathlib probability if desired.

## 6. Certificates (`Certificates/`)
- **C6.1 (LP certificate checker).** Given rational data (A sparse with entries in ℚ, b, c, l, u) and a rational candidate (y ≥ 0, split r⁺, r⁻ with c − Aᵀy = r⁺ − r⁻): the theorem `cert_bound : ∀ x, A x ≤ b → l ≤ x ≤ u → cᵀx ≤ yᵀb + Σ(r⁺ u − r⁻ l)` (T1.3), and a decidable check that the supplied numbers satisfy the hypotheses; a `certificate.json` → Lean data path (rationalized coefficients: the floating-point boxes are enclosed outward into rationals before export). (`NumericalChecker.lean`)
- **C6.2 (difference-constraint witness checker).** Given rational bounds, arc costs and a rational vector x: decide l ≤ x ≤ u and x_q − x_p ≤ c_pq for all arcs; theorem: a vector passing the check is in Φ, hence dᵀx ≤ h_Φ(d) (lower bound certificate).
